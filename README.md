README
In today's rapidly evolving AI era, technology is no longer a barrier to bringing creative ideas to life. Anyone can direct a machine to build a project using simple natural language. However, as we discussed in class, understanding the boundaries of AI use has become essential. Machines cannot replace genuine thought—they can only offer choices. While this shift seems to make design more accessible, it can actually limit our creative agency. Learning the fundamentals of programming empowers us to use machines effectively as tools, keeping the autonomy of aesthetic judgment firmly in our own hands.
